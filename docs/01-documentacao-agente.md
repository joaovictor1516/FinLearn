# Documentação do Agente
## Caso de Uso
### Problema
Muitas pessoas têm dificuldade em entender o básico de finanças pessoais, como tipos de investimento, tipos de emprestimos, como organizar seus gastos e como ter uma reserva de emergência.
### Solução
Um agente que explica conceitos financeiros de forma simples, podendo usar os dados do cliente como exemplo prático, mas nunca dar recomendações de investimentos.
